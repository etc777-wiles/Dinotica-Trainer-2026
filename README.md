## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Dinotica**. This trainer provides optional gameplay assistance for Dinotica, including improved survivability, stronger attacks, faster progression, resource support, and enhanced Dino companion management. It is designed for single-player sessions and should be used carefully around co-op features.

**Target Audience:** Players who want to experiment with Dino teams, explore stages more freely, reduce repetitive resource gathering, test settlement layouts, or make boss encounters and roguelite progression more accessible.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Start the trainer before loading a save, then activate the movement option when the player character is controllable. Use moderate speed values in cramped settlement areas to avoid overshooting interactable objects. Disable the option before precision platforming or when joining a co-op session.

### Tools & Inventory

Activate the resource multiplier before gathering materials used for crafting, farming, construction, and settlement expansion. Collect one resource after enabling the option to confirm that it is working. Avoid changing inventory-related values while storage menus, crafting screens, or reward panels are open.

### World & Environment

Use defensive options while exploring dangerous stages and deeper areas where enemy strength increases. Resource assistance is useful for building farms, beds, decorations, and other settlement structures. Save the game normally after completing major upgrades, then disable the trainer before switching chapters or modes.

### Combat & Weapons

Enable player and Dino protection before entering a boss arena or a difficult stage. The damage multiplier can speed up regular encounters and boss phases, while instant ability recovery supports builds centered on companion skills. Disable combat options when testing normal balance, achievements, or co-op gameplay.
